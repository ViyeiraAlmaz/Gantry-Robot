# TechDoc — Gantry Robot

## 1. Overview

**Gantry Robot** — учебный проект автоматизированной сборочной ячейки, разработанный для практики по робототехнике и промышленной автоматизации.

Проект объединяет:

- **Siemens S7-300** как контроллер;
- **TIA Portal V20** как среду разработки PLC-программы;
- **S7-PLCSIM** для виртуального исполнения программы PLC;
- **Factory I/O** со сценой **Assembly / Assembler Control** как 3D-модель технологического процесса.

Основная программа выполнена на **LAD (Ladder Logic)**. Основная циклическая логика находится в `OB1`.

> Важно: ниже используются только сведения, подтверждённые предоставленным экспортом программы, презентацией и описанием проекта. Отдельные FC/FB и ручной режим не заявляются как факт, поскольку в предоставленном экспорте они явно не подтверждены.

## 2. Цель

Цель проекта — реализовать и виртуально проверить управление сборочной ячейкой с подачей компонентов, их позиционированием и зажимом, работой Gantry Robot по осям X/Z, захватом и выдачей собранного изделия.

## 3. Архитектура

```text
┌──────────────────────────────┐
│        Factory I/O           │
│  Assembly / Assembler Control│
│  3D-сцена, датчики, приводы  │
└──────────────┬───────────────┘
               │ I/O mapping
               ▼
┌──────────────────────────────┐
│          S7-PLCSIM           │
│      виртуальное исполнение  │
│         PLC-программы        │
└──────────────┬───────────────┘
               │
               ▼
┌──────────────────────────────┐
```

S7-300 был выбран в проекте из-за большего количества доступных входов/выходов, необходимого для моделируемой сборочной ячейки.

## 4. Технологический объект

В Factory I/O используются следующие основные элементы:

- конвейер подачи оснований;
- конвейер подачи крышек;
- эмиттер основания;
- эмиттер крышек;
- датчики положения;
- зажим основания;
- зажим крышки;
- механизм перемещения Gantry по X и Z;
- захват `Grab`;
- механизм позиционирования основания;
- датчик выхода готовой детали.

## 5. Последовательность работы

### Шаг 1 — запуск

Вход `I1.2 Start` используется как команда запуска. Дополнительный вход `I1.7 Factory I/O Running` учитывается для работы с виртуальной сценой.

### Шаг 2 — подача компонентов

Активируются эмиттеры:

- `Q1.4 Base emitter`;
- `Q1.5 Lids emitter`.

Далее используются конвейеры:

- `Q0.6 Bases conveyor`;
- `Q0.3 Lids conveyor`.

### Шаг 3 — позиционирование

Положение деталей контролируется датчиками:

- `I0.3 Lid at place`;
- `I0.6 Base at place`.

При достижении рабочего положения соответствующий конвейер прекращает дальнейшую подачу, а программа переходит к операции фиксации.

### Шаг 4 — зажим

Используются:

- `Q0.4 Clamp lid`;
- `Q0.7 Clamp base`.

Факт фиксации подтверждается:

- `I0.4 Lid clamped`;
- `I0.7 Base clamped`.

### Шаг 5 — работа Gantry Robot

Портальный механизм использует:

- `Q0.0 Move X`;
- `Q0.1 Move Z`;
- `Q0.2 Grab`.

Обратные сигналы положения:

- `I0.0 Moving X`;
- `I0.1 Moving Z`.

### Шаг 6 — временные операции

В программе используются TON-таймеры:

| Таймер | Уставка | Назначение |
|---|---:|---|
| T0 | 3 s | временная выдержка операции захвата/перемещения |
| T1 | 1 s | временная выдержка следующей стадии |
| T2 | 3 s | обработка состояния выхода детали |
| T3 | 100 ms | короткая задержка для управления подачей |

Таймеры представлены DB `T0`–`T3`.

### Шаг 7 — выход изделия

Вход `I1.1 Part leaving` фиксирует выход готового изделия из рабочей зоны. После этого соответствующее внутреннее состояние сбрасывается через временную логику `T2`.

## 7. Программная структура

Основная циклическая программа:

- `OB1` — Main Program Sweep (Cycle), язык `LAD`.

В `OB1` реализованы сети управления подачей, конвейерами, зажимами, движением Gantry, захватом, выходом изделия и сбросом.

Используются внутренние маркеры `%M...` для хранения промежуточных состояний.

## 8. Управление подачей

Сигналы запуска подают основания и крышки в систему. Например:

- `Base emitter` — `%Q1.4`;
- `Lids emitter` — `%Q1.5`.

В программе предусмотрена временная обработка состояния эмиттера через `T3`.

## 9. Управление зажимами

Для крышки:

1. обнаруживается `Lid at place`;
2. включается `Clamp lid`;
3. ожидается подтверждение `Lid clamped`;
4. после подтверждения система может переходить к следующей операции.

Для основания аналогично:

1. обнаруживается `Base at place`;
2. включается `Clamp base`;
3. ожидается `Base clamped`.

## 10. Управление Gantry

Движение выполняется отдельными дискретными командами:

- `Move X` — горизонтальное перемещение;
- `Move Z` — вертикальное перемещение;
- `Grab` — захват.

Последовательность переходов между операциями реализована через внутренние биты и условия LAD.

## 11. Reset

Вход `I1.3 Reset` используется для сброса внутренних состояний. В программе присутствует операция `MOVE`, связанная с обнулением соответствующих данных/переменных.

## 12. Проверка в Factory I/O

Проект предназначен для software-in-the-loop проверки:

1. открыть проект в TIA Portal V20;
2. подготовить конфигурацию S7-300;
3. запустить S7-PLCSIM;
4. запустить сцену Assembly / Assembler Control в Factory I/O;
5. проверить соответствие I/O mapping;
6. запустить виртуальную программу;
7. подать `Start`;
8. наблюдать последовательность подачи, позиционирования, зажима, перемещения Gantry, захвата и выхода изделия.

## 13. Типовые проблемы

### Factory I/O не реагирует на PLC

Проверить:

- запущен ли S7-PLCSIM;
- запущена ли сцена Factory I/O;
- выбран ли правильный драйвер;
- совпадают ли адреса I/O.

### Конвейер не останавливается

Проверить датчик соответствующего положения:

- `Base at place`;
- `Lid at place`.

### Gantry не перемещается

Проверить:

- разрешающие условия LAD;
- `Move X`;
- `Move Z`;
- обратные сигналы положения.

### Захват не выполняет операцию

Проверить:

- `Grab`;
- подтверждение положения по Z;
- выдержку `T0/T1`;
- последовательность внутренних маркеров.

## 14. Результат

В результате создана виртуальная система управления сборочной ячейкой, позволяющая проверить PLC-алгоритм до применения физического оборудования. Связка TIA Portal V20 + S7-PLCSIM + Factory I/O обеспечивает визуальную проверку состояния датчиков и исполнительных механизмов.
